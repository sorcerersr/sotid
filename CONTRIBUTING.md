# Contributing to Sotid

Thank you for helping make Sotid better!

## Build and test

Sotid is built from source. Follow the guide for
[macOS](./docs/src/development/macos.md),
[Linux](./docs/src/development/linux.md), or
[Windows](./docs/src/development/windows.md).

Build and manually test your changes before opening a PR.

## Opening a PR

- Keep each PR about one thing; leave unrelated changes for another PR.
- For visual changes, attach screenshots or a video.
- Follow the [pull request template](./.github/pull_request_template.md)
  for testing details and the self-review checklist.

All activity in this repository is subject to our
[Code of Conduct](./CODE_OF_CONDUCT.md).
